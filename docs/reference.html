Not all boundaries shrink the same way.

An interior class component loses a radius from each end. Its endpoint flags survive: a closed interval can shrink to one robust point; an open interval cannot.

An included domain edge does not shrink. The perturbation ball is intersected with the declared domain, so there is nothing to classify beyond it.

For margin(x) = x on [-2, 2] at radius 1, robust class-0 references are [-2, -1), while class-1 references are [1, 2]. The class-1 tie at zero changes which shifted endpoint is included.

All references, not arbitrary networks.

The base contract is unchanged: one scalar input, one or two hidden ReLU layers of width 1..3, one scalar margin. All input rational values have absolute value at most 32 and reduced denominator at most 1,024. The domain is a nonempty closed interval. Class 1 owns every zero-margin tie. Only the closed ball intersected with this domain is checked.

Robust fraction is exact interval length divided by domain length. It is not accuracy or probability under a data distribution. Singleton sets have zero length but are retained as real references.

The forward generator erodes exact class components. A separate checker enumerates activation masks, splits all boundary/root atoms and their radius-shifted critical points, then checks opposite-class intersection with the closed ball. It calls neither the reference generator nor its erosion or union routines. A browser report becomes independently checked only after Python accepts the downloaded JSON.

This uses established piecewise-affine analysis and set erosion, not a new verification algorithm. Relative-domain clipping and endpoint ownership are explicit. No model training/import, high-dimensional certificate, sampled-grid proof or benchmark claim. See the source's REFERENCE.md and SOURCES.md for the exact definition and attribution.
