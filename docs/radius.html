Length can vanish before the last point.

Each class component loses length at speed zero, one or two as radius grows. Exact breakpoints assemble a complete profile on [0, 32], rather than a sweep over a sampled grid.

For margin(x) = x on [-2, 2], the robust length reaches zero at radius 2. Class 0 is already empty there, but the class-1 endpoint {2} still exists. At every radius above 2 both sets are empty.

The inverse query finds the first radius whose total robust length is at most the chosen fraction of domain length. A zero target is about length, not absence of robust points. A constant class may never reach your target.

The network's saved radius and reference remain required by the shared schema, but neither changes this all-radius calculation.

Exact within a deliberately small contract.

One scalar input, one or two hidden ReLU layers of width 1..3 and a scalar margin. Class 1 owns zero-margin ties. Input rationals have absolute value at most 32 and reduced denominator at most 1,024. Every closed perturbation ball is intersected with the declared nonempty closed domain. Radius horizon is [0,32]; the target fraction is in [0,1]. Computed rational breakpoints are not rounded to input limits.

Length fraction is not accuracy or probability under a data distribution. A zero-length singleton still exists. An unattained target means no radius in this horizon meets the length target, not that the network is globally certified.

The generator sums each exact class component's clipped affine length. A separate Python checker enumerates activation masks, class atoms and all candidate collision radii from boundary differences and half-differences. It reconstructs length at exact interior probes through opposite-class closed-ball intersection, and checks boundary values and existence separately. No forward profile, reference-atlas, union or erosion generator is imported by that checker. It shares only parsing, direct evaluation and the independent base mask enumerator. Python must accept the downloaded evidence before it is independently checked.

This uses established piecewise-affine analysis and morphological erosion. No new algorithm, imported or trained model, high-dimensional certificate, benchmark, grid proof or scaling claim.
