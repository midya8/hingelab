HingeLab / exact regions, honest limits

A decision boundary is not always an adversary.

Follow every affine region of a small ReLU network. Then ask whether the nearest class change is attained, only approached, or absent inside the domain.

Rational arithmeticIndependent mask checkerOne-dimensional, bounded

The endpoint changes the answer.

The classifier is class 1 when the scalar margin is at least zero, and class 0 otherwise. A zero-margin point is therefore a class-1 tie, not a universal class change.

From the positive side of margin(x) = x, the opposite class occupies an open interval. Its distance has an infimum, but no nearest point. A closed ball whose radius equals that infimum is still robust.

From the negative side, the tie belongs to the opposite class. The same radius now includes an actual adversary. The convention is fixed, visible and checked.

All roots, interval endpoints and decisions use exact fractions. Only SVG coordinates are rounded for display. No sampled curve is used as verification.

Every segment comes from its exact affine formula. Vertical rules are activation-region boundaries, even when the output slope does not change. The teal point is the reference.

Every affine region

Closed endpoint formulas agree by network continuity. Masks describe the open interior; a zero preactivation is canonically inactive. Adjacent regions are retained when hidden activations differ, even if their output formulas coincide.

Exact for this contract, not for arbitrary networks.

One scalar input, one or two hidden ReLU layers, width 1..3 per layer, one scalar margin. Integer or rational-string parameters, absolute value at most 32 and input denominator at most 1,024. The reference must lie in a nonempty closed domain. At most six hidden units: the independent checker examines all 64 masks at the largest allowed shape. There is no floating-point model import, training, image classifier, high-dimensional certificate or benchmark claim.

The generator propagates and splits affine intervals. The independent checker enumerates every activation mask, solves its rational phase inequalities and checks the full interval union and all boundary atoms. It does not call the generator. A browser report becomes checked evidence only when the Python checker accepts its downloaded JSON.

Zero-set entries are per-cell witnesses and may repeat a shared endpoint; they are not claimed to be a minimal union. Lipschitz is the exact maximum absolute output slope over this domain, not a product-of-layer-norm bound. Changing the domain can change robustness.

This is a bounded educational implementation of established piecewise-affine network analysis, not a new verification algorithm. Computing Linear Restrictions of Neural Networks (2019) studies exact line restrictions. Branch and Bound for Piecewise Linear Neural Network Verification (2020) covers broader verification methods. HingeLab does not implement or benchmark those full systems.
